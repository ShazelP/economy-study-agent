# 경제 공부 에이전트

경제 신문 1면 사진을 노션에 업로드하면, 에이전트가 자동으로 기사를 분석하고 주간 정리를 생성합니다.

> 특정 신문에 종속되지 않습니다 — 매일경제, 한국경제 등 본인이 원하는 경제신문 1면으로 쓰면 됩니다.

---

## 목적

- 매일 신문을 보는 루틴을 **수동 정리 없이** 자동화
- 신문 사진 + 사용자 메모 + 웹 검색을 결합해 분석 정확도 향상
- 사진에서 **?(물음표)** 표시한 용어를 자동으로 설명
- 주간 단위로 한 주의 경제 흐름을 종합 인사이트로 정리
- 주간 복습 퀴즈 3문제 자동 생성 (정답은 토글로 숨김)
- 연속 출석 스트릭 및 월별 출석률 자동 집계

---

## 노션 DB 구조

| DB | 역할 |
|----|------|
| 📅 일일 학습 | 매일 신문 사진 업로드. 에이전트가 날짜·요일·키워드·체크박스 자동 입력 |
| 📊 주간 정리 | 에이전트가 자동 생성. 일별 기사 정리 + AI 인사이트 + 퀴즈 포함 |

### 일일 학습 DB 속성
- **제목**: `YYYYMMDD_요일` (예: `20260522_금`) — 에이전트가 제목에서 날짜·요일 자동 파싱
- **날짜**: 에이전트가 자동 입력 (수동 입력 불필요)
- **요일**: 에이전트가 자동 입력 (수동 입력 불필요)
- **핵심 키워드**: 에이전트가 자동 입력
- **AI 첨언 완료**: 에이전트 처리 완료 시 자동 체크
- **출석**: 에이전트 처리 완료 시 자동 체크

### 사용자가 할 일 (매일)
1. 경제 신문 1면 사진 촬영 후 노션 일일 학습 DB 해당 날짜 페이지에 붙여넣기 (매일경제, 한국경제 등 본인이 보는 신문으로)
2. (선택) 헤드라인·주요 내용을 텍스트로 메모 → 에이전트가 기사 분석의 핵심 참고 자료로 활용
3. (선택) 모르는 용어에 **?** 표시 → 에이전트가 자동으로 용어 설명 생성

> **팁**: 글씨를 또렷하게 쓸수록 이미지 판독 정확도가 높아집니다. 헤드라인 메모를 함께 남기면 분석 품질이 크게 향상됩니다.

## 에이전트 동작 방식

### 주간 에이전트 실행 흐름

```
1. 해당 주 일일 페이지 조회
   └ 제목(YYYYMMDD_요일) 기반으로 해당 주 범위 판단
   └ AI 첨언 완료 = False인 항목만 처리 대상

2. 날짜별 이미지 분석
   └ 신문 사진(주요 출처) + 사용자 메모(핵심 참고) + 웹 검색(보조 확인)
   └ 사진의 ? 표시 용어 → 용어 설명 자동 생성
   └ 날짜·요일·키워드·출석 자동 입력

3. 분석 결과 검토
   └ 각 날짜별 기사 내용·키워드 품질 자동 점검
   └ 이슈 발견 시 터미널에 경고 출력 후 계속 진행

4. 주간 인사이트 생성
   └ 종합 요약 / 핵심 테마 / 거시경제 맥락 / 투자·생활 인사이트 / 다음 주 주목 포인트

5. 주간 퀴즈 생성 (실패 시 자동 재시도 1회)

6. 출석 통계 계산
   └ 연속 출석 스트릭 / 월별 출석률

7. 주간 정리 DB에 저장
```

### 주간 정리 페이지 구성

```
🔥 연속 출석 N일 연속
📅 YYYY년 M월 출석률 N/M일 (X%)

📰 일별 기사 정리
  └ 날짜별
      └ ▶ 기사 제목
          - 무슨 일
          - 원인/배경
          - 파급 효과
      └ 📖 용어 정리 (사진 ? 표시 또는 사용자 메모 기반)

🤖 주간 AI 인사이트
  └ 이번 주 종합 요약
  └ 핵심 테마
  └ 거시경제 맥락
  └ 투자 인사이트
  └ 생활 인사이트
  └ 다음 주 주목 포인트

❓ 이번 주 퀴즈
  └ Q1. [인과관계 문제]  A/B/C/D 선택지
      └ ▶ 정답 보기 (토글 — 클릭하면 정답·해설 표시)
  └ Q2. ...
  └ Q3. ...
```

## 설치 및 환경 설정

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. .env 파일 설정
```bash
cp .env.example .env
```

`.env`에 아래 값 입력:
```
NOTION_TOKEN=secret_...          # 노션 Integration 토큰
GEMINI_API_KEY=AIza...           # Google AI Studio API 키
DAILY_DB_ID=...                  # 일일 학습 DB ID
WEEKLY_DB_ID=...                 # 주간 정리 DB ID
```

**노션 DB ID 찾는 법**: 브라우저에서 DB를 열면 URL이
`notion.so/.../xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=...` 형태.
`?v=` 앞의 32자리가 DB ID.

**노션 Integration 연결**: 각 DB 페이지 우상단 `...` → Connections → 생성한 Integration 추가 필요

## 사용 방법

### 터미널 실행 방법

1. Mac에서 **터미널** 앱 열기 (Spotlight에서 "터미널" 검색)
2. 아래 명령어로 프로젝트 폴더로 이동
```bash
cd /Users/soyeonpark/Desktop/economy_study-agent
```
3. 실행 명령어 입력

> Claude Code 대화창에서도 실행 가능 — 명령어 앞에 `!`를 붙이면 됩니다.
> 예: `! python main.py weekly`

---

### 주간 정리 (매주 주말 실행 권장)
```bash
# 이번 주 정리
python main.py weekly

# 특정 날짜가 속한 주 정리 (지난주 재실행 등)
python main.py weekly 2026-05-22
```

### 자주 쓰는 시나리오

**주말에 한 주 마무리**
```bash
python main.py weekly
```

**지난주 처리를 놓쳤을 때**
```bash
python main.py weekly 2026-05-22   # 해당 주에 속한 날짜 아무거나
```

**특정 날만 다시 처리하고 싶을 때**
1. 노션에서 해당 날짜 페이지의 **AI 첨언 완료** 체크박스 해제
2. 재실행
```bash
python main.py weekly 2026-05-22
```

## Gemini API 사용량

무료 티어 기준 하루 20회 호출 한도. 정상적으로 주 1회 실행 시 약 8~9회 사용으로 여유 있음.

| 상황 | 호출 수 |
|------|---------|
| 일별 이미지 분석 | 최대 6회 (월~토) |
| 주간 인사이트 생성 | 1회 |
| 퀴즈 생성 (재시도 포함) | 최대 2회 |
| **1회 실행 합계** | **~8~9회** |

> 같은 주를 여러 번 재실행하면 한도 초과 가능. 유료 전환 시 제한 없음.

## 주의사항

- `.env` 파일은 절대 git에 커밋하지 마세요 (API 키 노출)
- Gemini API는 Google AI Studio에서 발급 (aistudio.google.com)
- 노션 Integration이 두 DB 모두에 연결되어 있어야 함
- 이미 처리된 항목(AI 첨언 완료 = True)은 재실행해도 건너뜀
- 날짜·요일 속성은 수동 입력 불필요 — 에이전트가 제목에서 자동 파싱하여 채움
