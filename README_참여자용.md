# 매경 1면 경제 스터디 참여 가이드

## 스터디 소개

매일 매일경제 신문 1면을 보고 기록하는 경제 공부 스터디입니다.
사진만 올리면 AI가 기사를 분석하고 주간 정리까지 자동으로 만들어줍니다.

---

## 참여자가 할 일

### 매일 (신문 보는 날)

1. 매일경제 신문 1면 사진 촬영
2. 노션 **📅 일일 학습 (매경 1면)** DB에서 오늘 날짜 페이지 열기
3. 사진을 페이지 본문에 붙여넣기
4. (선택) 모르는 용어나 궁금한 점을 텍스트로 메모
   - 예: `"양도세가 뭔지 모르겠음"`, `"QE란?"`
   - 메모해두면 AI가 주간 정리할 때 해당 용어를 설명해줍니다

### 매주 토요일 이후

- 별도로 할 일 없음 — 운영자가 주간 정리를 실행합니다
- 노션 **📊 주간 정리** DB에 자동으로 정리 내용이 올라옵니다

---

## 노션 페이지 구조

### 일일 학습 페이지 (내가 채우는 부분)
```
[페이지 본문]
- 신문 사진 (필수)
- 모르는 용어 메모 (선택)
```

### 주간 정리 페이지 (자동 생성)
```
📰 일별 기사 정리
  └ 날짜별 기사 제목
      - 무슨 일 / 원인 / 파급 효과
  └ 📖 용어 정리 (내가 메모한 용어 설명)

🤖 주간 AI 인사이트
  └ 이번 주 종합 요약
  └ 핵심 테마
  └ 거시경제 맥락
  └ 투자 인사이트
  └ 생활 인사이트
  └ 다음 주 주목 포인트
```

---

## 출석 체크

- 사진을 올리고 AI 분석이 완료되면 **출석** 체크박스가 자동으로 체크됩니다
- 별도로 출석 체크를 할 필요 없습니다

---

## 자주 묻는 질문

**Q. 사진이 흐려도 괜찮나요?**
AI가 이미지 분석과 웹 검색을 함께 사용하므로 흐린 사진도 분석 가능합니다.

**Q. 용어 메모는 어디에 쓰면 되나요?**
노션 일일 학습 페이지 본문에 사진 아래 텍스트로 자유롭게 적으면 됩니다.

**Q. 주간 정리는 언제 올라오나요?**
매주 토요일 이후 운영자가 실행하면 자동으로 생성됩니다.
